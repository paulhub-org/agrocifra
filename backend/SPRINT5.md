# Спринт 5 — Отчёты и визуализация (27 июля – 9 августа 2026)

## Бэкенд
- **Агрегация** (`app/services/reporting.py`): `summary` (общие показатели, разрез
  по регионам, эффективность и зрелость по организациям, распределение по зонам);
  `organization_report` — карточка организации со сравнительными рядами «до/после»
  (строятся из сохранённых нормализованных входных полей оценки).
- **Экспорт** (`app/services/exporters.py`): Excel (openpyxl — листы «Эффективность»,
  «Зрелость», «Сводка по регионам»), Word (python-docx — оформление приложения к
  диссертации, таблицы 1–3), PDF (reportlab с кириллическим шрифтом DejaVu).
- **API** (`app/api/reports.py`): `GET /reports/summary`,
  `GET /reports/organization/{id}`, `GET /reports/export.{xlsx,docx,pdf}`
  (потоковая отдача файлов, имена в UTF-8). Все эндпоинты под аутентификацией.

## Фронтенд (React + Plotly)
- Раздел **«Отчёты»** (`Reports.jsx`):
  - Интерактивные графики (Plotly): КЭц по организациям (цвет по зоне, порог 1,0),
    цифровая зрелость по организациям (линии порогов 0,134 / 0,366), среднее КЭц
    по регионам.
  - **Сравнительный вид «до/после»**: выбор организации → сгруппированные столбцы
    (ДО = 100 %, ПОСЛЕ относительно ДО) и таблица с Δ, %.
  - Кнопки экспорта в Word / Excel / PDF (скачивание с авторизацией).
- Пункт меню «Отчёты»; единое оформление.

## Тесты (67, ruff чистый)
- `summary`: 6 оценок эффективности (среднее КЭц 0,99), 7 оценок зрелости
  (среднее 0,42), разрез по регионам, число эффективных.
- `organization_report`: ряды «до/после» («Доброволец»: урожайность 0,47 → 0,48).
- Экспорт: Excel читается openpyxl (3 листа), Word — python-docx (таблицы),
  PDF начинается с `%PDF`. Эндпоинты экспорта возвращают корректные типы.

## Запуск
Эндпоинты доступны после `alembic upgrade head` и входа; раздел «Отчёты» — в меню
веб-интерфейса. Шаблоны выходных отчётов — образцы экспорта (Word/Excel/PDF).
