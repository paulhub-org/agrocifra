# Спринт 4 — Пользовательский интерфейс и ролевая модель (13–26 июля 2026)

## Бэкенд
- **Аутентификация JWT** (`app/core/security.py`): bcrypt-хеширование паролей,
  выпуск/проверка токенов (HS256). Эндпоинты `POST /auth/login`
  (OAuth2 password flow) и `GET /auth/me` (`app/api/auth.py`).
- **Ролевая модель — 4 роли** (`Role`): организация, региональный оператор,
  офис цифровизации, государственный орган. Поле `UserAccount.role` (+ `full_name`,
  `email`, `is_active`, `region_id`). Миграция перегенерирована.
- **Контроль доступа** (`app/core/deps.py`): `get_current_user`, `require_roles(...)`.
  Применён к данным: списки — для аутентифицированных; синхронизация Jotform — для
  офиса цифровизации/госоргана; импорт Excel — для офиса цифровизации.
- **Ручной ввод данных**: `POST /data/assessments/efficiency` и
  `POST /data/assessments/maturity` — расчёт (КЭц / зрелость) и сохранение.
- **Демо-данные** (`app/db/seed.py`): пользователи org/region/office/gov и регионы.

## Фронтенд (React + Vite)
- Маршрутизация `react-router-dom` с защитой по аутентификации и ролям (`App.jsx`).
- Контекст аутентификации с хранением JWT (`auth.jsx`), API-клиент (`api.js`).
- Экраны: вход, дашборд (плитки и последние оценки), организации, оценки
  (эффективность/зрелость), формы ручного ввода эффективности и зрелости.
- Боковое меню с ролевой фильтрацией пунктов; единое оформление (тема «агро»).

## Тесты (58, ruff чистый)
- Вход выдаёт токен и роль; `/auth/me`; неверный пароль → 401; без токена → 401.
- RBAC: «организация» → 403 на синхронизации; «офис цифровизации» допущен.
- Ручной ввод: эффективность «Доброволец» → КЭц 1,1152; зрелость → зона «высокая».

## Запуск
Бэкенд: `alembic upgrade head && python -m app.db.seed && uvicorn app.main:app --reload`.
Фронтенд: `npm install && npm run dev`. Подробности и сценарии — `docs/UAT_протокол.md`.
