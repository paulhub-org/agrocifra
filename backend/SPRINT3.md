# Спринт 3 — Слой данных и интеграция Jotform (29 июня – 12 июля 2026)

Реализованы слой данных, интеграция с Jotform и ETL-пайплайн, подающий данные
в расчётное ядро (Спринт 2).

## Что реализовано
- **Схема БД и миграции (Alembic).** Новые таблицы: `raw_submission` (сырые
  ответы для трассируемости и идемпотентности), `maturity_assessment`,
  `efficiency_assessment`. Начальная миграция `migrations/versions/*_initial_schema.py`
  создаёт все 13 таблиц; проверена upgrade/downgrade.
- **Клиент Jotform REST API** (`app/services/jotform_client.py`) — выборка
  сабмишенов/вопросов из EU-облака с постраничной итерацией; транспорт
  внедряется (тестируется через httpx.MockTransport).
- **Сопоставление полей** (`app/services/jotform_mapping.py`) — карта qid формы
  «Эффективность» (222133487281353) → входы индексной формулы КЭц (установлена
  по формуле виджета, верифицирована в Спринте 2); зрелость — по настраиваемым
  спискам qid потребности/возможностей.
- **Нормализация/валидация** (`app/services/normalize.py`) — русская запятая
  («0,69»→0.69), разделители разрядов, прочерки/пустые → None, контроль
  положительности знаменателей.
- **Импорт Excel/CSV** (`app/services/importers.py`) — листы «Цифровая зрелость»
  и «Эффективность цифровизации» пилотной книги; произвольный CSV.
- **ETL-пайплайн** (`app/services/etl.py`) — извлечение (Jotform/Excel/JSON) →
  нормализация и сопоставление → расчёт (КЭц / цифровая зрелость) → загрузка в БД,
  идемпотентно по паре «источник + внешний идентификатор».
- **API слоя данных** (`app/api/data.py`) — выборка организаций и оценок,
  синхронизация с Jotform, загрузка Excel.

## Верификация (тесты на SQLite, 47 тестов, ruff чистый)
- Импорт зрелости из пилотной книги → 7 организаций, среднее **0,42** ✓.
- Импорт эффективности (6 организаций) → 4 с полными данными воспроизводят
  опубликованный КЭ (1,12 / 0,91 / 1,22 / 0,81), среднее **0,99** ✓.
- Синхронизация Jotform (MockTransport, «Доброволец») → КЭц **1,1152** ✓;
  повторная синхронизация идемпотентна (дубликаты не создаются) ✓.

## Карты полей Jotform (подтверждены выгрузкой соискателя «Список_QID»)
- **Эффективность** (222133487281353): 16 из 17 полей сверены с текстами выгрузки
  (`EFFICIENCY_TEXT_MAP`); поле «урожайность ПОСЛЕ» в выгрузке отсутствует, но
  присутствует в сабмишене (qid 42). Резолвинг ответа: по qid, затем по тексту.
- **Цифровая зрелость**: итог формируется двумя агрегатами — «Среднее значение
  показателей потребности/возможностей» (резолвинг по тексту), далее
  КЗ = Гурвиц(потребность, возможности, 0,5), классификация 0,134 / 0,366.

## Требуется от соискателя
1. **Идентификатор формы «Цифровая зрелость»** → `JOTFORM_FORM_MATURITY`.
   ВНИМАНИЕ: форма **222084057175050**, числящаяся как «Трансформация», по данным
   live-метаданных — отдельный **банковский опросник** (вопросы о кредиторах,
   диагностике должника), а НЕ форма цифровой зрелости. Нужен корректный ID формы,
   чьи поля приведены в листе 1 «Список_QID». Форма эффективности (222133487281353)
   подтверждена.
2. **API-ключ Jotform** → `JOTFORM_API_KEY` (база `JOTFORM_API_BASE=https://eu-api.jotform.com`).
3. Урожайность «ПОСЛЕ» для Excel-импорта — параметром `yield_after` (в книге её нет).
