скорректированы сопоставление полей, модель свёртки зрелости и пилотные данные.

## Эффективность цифровизации (КЭц)
- Индексная формула КЭц **не изменилась** и воспроизводит интегральный показатель
  формы (строка r55) для всех **7 из 7** организаций (среднее ≈ **1,00**):
  Шипяны 1,19; Достоево 1,21; ДолжаАгро 0,56; Криничная 1,06; Олекшицы 1,00;
  Минскоблагросервис 0,90; Учхоз 1,08.
- Изменения сопоставления полей (форма стала детальнее):
  - «Урожайность ПОСЛЕ» отдельным полем не хранится — **вычисляется** как
    валовый сбор ÷ площадь обрабатываемых земель.
  - «Совокупные затраты» → «Направлено денежных средств (всего)»;
    «Сумма уплачиваемых налогов» → «Направлено денежных средств на уплату налогов
    и сборов …»; уточнены тексты прибыли (3.2.1 / 3.2.2).
  - Резолвинг полей переведён на сопоставление по тексту вопроса.

## Цифровая зрелость — уточнение модели
- Итоговый уровень — **геометрическое среднее** средних потребности и возможностей:
  **КЗ = √(потребность · возможности)**. Соответствие подтверждено на **7 из 7**
  организациях (например, √(0,21 · 1,01) = 0,46), среднее ≈ **0,35**.
- Это уточняет прежнюю реализацию (арифметическая свёртка/Гурвиц). Коэффициент
  оптимизма α более не используется и удалён из модели, API и интерфейса.
- Пороги зон сохранены: < 0,134 — низкая; [0,134; 0,366] — средняя; > 0,366 — высокая.
- **К сверке в диссертации (п. 2.2.2):** если в тексте итоговая свёртка зрелости
  описана как метод Гурвица, формулировку следует согласовать с фактически
  используемой формой геометрической свёрткой (аналогично уточнению КЭц).
