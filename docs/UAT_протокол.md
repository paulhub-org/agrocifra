# Протокол приёмочного тестирования (UAT) — Спринт 4
## АИС «АгроЦифра» · веб-интерфейс, ролевая модель и аутентификация

**Версия:** 0.1.0  **Дата:** июль 2026  **Ответственный:** соискатель Юхнюк П.П.

---

### 1. Цель
Подтвердить, что веб-интерфейс обеспечивает аутентификацию, разграничение прав по
четырём ролям, ручной ввод данных с расчётом показателей и просмотр результатов.

### 2. Тестовая среда и развёртывание
**Бэкенд (FastAPI):**
```bash
cd backend && pip install -e ".[dev]"
alembic upgrade head          # схема БД
python -m app.db.seed         # демо-пользователи и регионы
uvicorn app.main:app --reload # http://localhost:8000  (Swagger: /docs)
```
**Фронтенд (React + Vite):**
```bash
cd frontend && npm install
cp .env.example .env          # при необходимости указать VITE_API_BASE
npm run dev                   # http://localhost:5173
```

### 3. Учётные записи (демо, сменить перед эксплуатацией)
| Роль | Логин | Пароль | Назначение |
| --- | --- | --- | --- |
| Организация | `org` | `org123` | ввод данных своей организации |
| Региональный оператор | `region` | `region123` | просмотр по региону |
| Офис цифровизации | `office` | `office123` | синхронизация Jotform, импорт Excel |
| Государственный орган | `gov` | `gov123` | сводный просмотр |

### 4. Тестовые сценарии
| № | Сценарий | Шаги | Ожидаемый результат | Итог |
| --- | --- | --- | --- | --- |
| 1 | Вход в систему | Открыть /login, ввести `office`/`office123` | Переход на дашборд; в шапке — роль «Офис цифровизации» | ☐ |
| 2 | Неверный пароль | Ввести `office`/`wrong` | Сообщение «Неверный логин или пароль», входа нет | ☐ |
| 3 | Выход | Нажать «Выйти» | Возврат на /login; защищённые страницы недоступны | ☐ |
| 4 | Ролевое меню | Войти как `gov`, затем как `org` | У `gov` нет пунктов «Ввод …»; у `org` они есть | ☐ |
| 5 | Запрет действия | Войти как `org`, открыть синхронизацию Jotform | Операция недоступна (403) — кнопок синхронизации нет в меню | ☐ |
| 6 | Ввод эффективности | `org` → «Ввод · эффективность», заполнить поля, отправить | Показан КЭц, индексы и зона; запись появляется в «Оценках» | ☐ |
| 7 | Ввод зрелости | `org` → «Ввод · зрелость»: потребность 0,55, возможности 0,67 | Зрелость рассчитана, зона «высокая» | ☐ |
| 8 | Дашборд | Войти как `gov` | Плитки: число организаций, среднее КЭц, средняя зрелость и т.д. | ☐ |
| 9 | Организации/Оценки | Открыть разделы | Таблицы заполнены ранее введёнными данными | ☐ |
| 10| Синхронизация Jotform* | `office` → синхронизация | Загрузка сабмишенов и расчёт (требует API-ключа и ID формы) | ☐ |

\* Сценарий 10 выполняется после предоставления `JOTFORM_API_KEY` и идентификатора
формы цифровой зрелости (`JOTFORM_FORM_MATURITY`).

### 5. Критерии приёмки
- Сценарии 1–9 пройдены без ошибок.
- Разграничение прав соответствует ролям (сценарии 4–5).
- Расчётные значения совпадают с расчётным ядром (Спринт 2).
